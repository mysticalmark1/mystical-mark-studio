# Start here — Studio 1.1.1

Existing Linux/systemd user: extract into a new folder, read [UPGRADING.md](docs/UPGRADING.md), then run `bash install.sh` without sudo. Keep your existing data and installation. Your password, content and HTTPS setup are preserved; a private snapshot is made before migration.

New user: follow [README.md](README.md), then configure **Settings & backup → Private creator profile**. New installs have an empty planner.

The release includes manual Windows/macOS instructions, but those native deployment paths are not verified. Linux remains the primary setup.

Monthly-task fix: choose work mode, select all weekly registers and assessments together, and create the monthly task again. The aggregate 750,000-character limit no longer applies to Work packets.
